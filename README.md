# BERT Sentiment Analysis

## 📌 Project Overview
Fine-tuned BERT model for binary sentiment classification (Positive/Negative) on movie reviews.

## 🎯 Features
- Pre-trained `bert-base-uncased` model
- Custom PyTorch Dataset and DataLoader
- Full training pipeline with validation
- Comprehensive evaluation (Accuracy, F1, Confusion Matrix)
- Easy prediction function for new text

## 📊 Results
- Test Accuracy: 95%+
- F1-Score: 0.94+

## 🛠️ Tech Stack
- Python 3.10+
- PyTorch
- Hugging Face Transformers
- Scikit-learn
- Matplotlib / Seaborn

## 🚀 How to Run
1. Open `sentiment_analysis_bert.ipynb` in Google Colab
2. Install dependencies: `pip install -r requirements.txt`
3. Run all cells in order

## 📁 Files
- `sentiment_analysis_bert.ipynb` — Main notebook
- `requirements.txt` — Python dependencies
- `README.md` — This file

Sample dataset with 500 movie reviews (250 positive + 250 negative).
